# Tugboat Yards

> Tugboat Yards Inc. was a San Francisco startup (product name "Tugboat") that built tools for independent publishers and media creators to raise direct financial support from their audiences. It was backed by a16z and is now defunct: the product was live circa 2012-2014, the domain was parked by 2016, and tugboatyards.com publishes no A/AAAA records as of 2026-07-21. Its API (https://api.tugboatyards.com) is offline; the surface below is a historical record recovered from the provider's own 2015 documentation via the Wayback Machine.

This profile is maintained by API Evangelist / APIs.io as part of the a16z venture-portfolio graph. There is no live API surface to integrate with.

## Historical API surface (archived 2015)

- [API reference (Wayback)](https://web.archive.org/web/20150207025009/https://tugboatyards.com/developer/api): Sphinx-built docs for the Tugboat Yards publisher API - key-check, pages, offers (+ issues), subscribers, orders, checkouts (deprecated), key-settings, placements, and Instant Payment Notification webhooks
- [Authentication (Wayback)](https://web.archive.org/web/20150207051224/https://tugboatyards.com/developer/api/authentication.html): API-key auth via the X-Tugboat-Auth header (app_id%token), validated with GET /key-check
- [pytugboat client docs (still live)](https://pytugboat.readthedocs.io/): First-party Python client, v0.1, copyright 2013 Tugboat Yards Inc.; never on PyPI, source repo deleted
